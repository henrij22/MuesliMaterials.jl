Material points

A material point carries the state at one location: the current deformation, the last converged state, and any internal variables. It is created from a material and then driven through a load history.

Types

MuesliMaterials.ElasticIsotropicMP — Type
ElasticIsotropicMP(material::ElasticIsotropicMaterial)

The material point of a linear isotropic elastic material.

Carries the state at one location. Push a strain into it with updateCurrentState, then read stresses, tangents and energies out of it.

Driving the state

MuesliMaterials.updateCurrentState — Function
updateCurrentState(mp, t::Real, strain::Istensor)
updateCurrentState(mp, t::Real, F::Itensor)

Set the trial state of the material point at time t.

Details

Small strain points take the linearised strain as an Istensor; finite strain points take the deformation gradient as a general Itensor.

This sets the current state only. A solver iterating on a step calls this repeatedly, then either accepts the step with commitCurrentState or discards it with resetCurrentState.

There is no bang, because the call advances the point's own history rather than filling an argument.

MuesliMaterials.tangentTensor! — Function
tangentTensor!(mp, ℂ::Itensor4)

Compute the small strain tangent $\partial\sigma/\partial\varepsilon$ into ℂ.

For a linear isotropic material this is $\mathbb{C}_{ijkl} = \lambda\delta_{ij}\delta_{kl} + \mu(\delta_{ik}\delta_{jl} + \delta_{il}\delta_{jk})$, and contracting it with the strain reproduces the stress.

Finite strain response

MuesliMaterials.firstPiolaKirchhoffStress! — Function
firstPiolaKirchhoffStress!(mp, P::Itensor)

Compute the first Piola-Kirchhoff stress $P$ into P.

$P$ is not symmetric, hence the general Itensor. It relates to the second Piola-Kirchhoff stress by $P = FS$.

MuesliMaterials.secondPiolaKirchhoffStress! — Function
secondPiolaKirchhoffStress!(mp, S::Istensor)

Compute the symmetric second Piola-Kirchhoff stress $S$ into S.

$S$ is unaffected by a rigid rotation of the deformation, which makes it the convenient measure for a material-frame formulation.

MuesliMaterials.firstPiolaKirchhoffStressNumerical! — Function
firstPiolaKirchhoffStressNumerical!(mp, P::Itensor)

Compute the first Piola-Kirchhoff stress by numerically differentiating the stored energy.

Slower and less accurate than firstPiolaKirchhoffStress!, and meant for checking: if the analytic and numerical stresses disagree, the model is wired up wrongly.

source
MuesliMaterials.secondPiolaKirchhoffStressNumerical! — Function
secondPiolaKirchhoffStressNumerical!(mp, S::Istensor)

Compute the second Piola-Kirchhoff stress by numerical differentiation of the stored energy.

Broken upstream

This does not currently produce a usable result. MUESLI's finiteStrainMP::secondPiolaKirchhoffStressNumerical assigns a general itensor into the symmetric istensor output, which never reaches the symmetric tensor's storage, so S keeps whatever was already in memory. It is intermittent — sometimes the memory happens to look plausible — which makes it worse than a hard failure.

Use firstPiolaKirchhoffStressNumerical!, which is correct, and convert with $S = F^{-1}P$ if you need the second measure.

Energies

MuesliMaterials.storedEnergy — Function
storedEnergy(mp)

The stored (elastic) energy density of the current state.

For linear elasticity this is $\tfrac{1}{2}\sigma:\varepsilon$, and for a hyperelastic material it vanishes at $F = I$.
